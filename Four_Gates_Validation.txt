## Gate 03: IDEMPOTENCY (Repeated Apply)
**Validation Checklist**:
- ✓ First `terraform apply` creates all resources
- ✓ Second `terraform apply` with no .tf changes results in "No changes" or only metadata updates
- ✓ State file is consistent after multiple applies
- ✓ Resource IDs remain stable across applies

**How to Test**:
```bash
terraform apply -auto-approve
# Wait for completion
terraform plan  # Should show "No changes"
terraform apply -auto-approve  # Should show "No changes" or minimal updates
terraform show | grep -E "resources"
```

**Pass Criteria**: After first apply, subsequent applies show `0 to add, 0 to change, 0 to destroy`
